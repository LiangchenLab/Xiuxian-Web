# 醒来直接看这个

## 正统玩法（语雀路线）

打开：**http://127.0.0.1:8766/game/**  
（或先双击 `start-phaser.bat`）

应能：主菜单 → 踏入青云山 → WASD 走动 → ESC 暂停。

对照说明：`docs/yuque-tutorial/对照说明.md`  
语雀原文：https://www.yuque.com/zeejk/kt12r4/moryiawbo9ftweqv?singleDoc

## 和「放置版」关系

- `web/`：闭关放置，可当练数值  
- `game/`：**主线**，Phaser 中大型架构（场景/实体/地图管理/事件总线）

## 建议你接着做（语雀下一步）

1. 注册 / 打开 **XMAI**，用 `prompts/from-yuque/01-角色立绘.txt` 出白底全身  
2. 用 `02-八向精灵` 做成行走/待机图，放进 `game/assets/images/characters/`  
3. 新开 Cursor 对话，粘贴 `prompts/from-yuque/00-总协作提示词.md`，说「架构已确认，开始问答调研」
