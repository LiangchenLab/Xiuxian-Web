## 五步流水线（每步只对 Cursor 说话）

1. **定玩法一页纸** → 已有 `docs/01-玩法一页纸.md`，你改数字/境界名即可  
2. **出美术圣经** → 用 `prompts/holopix-美术圣经.txt` 在 Holopix 建风格模型或批量出图  
3. **生成可玩骨架** → 对本仓说：`按 docs/01 实现 web 版放置修仙，别问我代码`  
4. **贴图替换** → 把 Holopix 导出丢进 `assets/ai/`，再说：`用 assets/ai 替换占位图`  
5. **调数值 / 上架材料** → 继续用自然语言迭代
