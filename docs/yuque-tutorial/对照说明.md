## 人家真正在做什么

| 项 | 语雀教程 | 我们之前的 `web/` 放置 |
|----|----------|------------------------|
| 引擎 | **Phaser.js** 中大型 HTML5 | 纯 DOM 点击放置 |
| 形态 | 俯视角修仙 RPG（走图/战斗/地图拼接） | 闭关条 + 突破 |
| 协作 | 固定总提示词 → 先架构 → **问答式**调研 → 再写码 | Agent 直接搓可玩壳 |
| 出图 | **XMAI** + 角色设定/8 向精灵/扩图地图 | Cursor 生 3 张静图 |
| 地图 | 2048 底图 + AI 扩图 + 5×5 拼接无限大地图 | 无 |
| 角色 | 白底立绘 → 替换参考精灵 8 向走/待机 → 抠图进游戏 | 一张半身立绘 |
