# Phaser 工程架构（对齐语雀「第一步」）

技术栈固定：**HTML + JavaScript + Phaser.js**，浏览器直接跑。

```
game/
  index.html                 # 入口
  lib/phaser.min.js          # 本地或 CDN（开发期可用 CDN）
  src/
    main.js                  # 启动 Phaser.Game、注册场景
    core/
      constants.js           # 常量（键位、层深、地图块尺寸）
      event-bus.js           # 全局事件总线
      game-state.js          # 存档级状态（境界、坐标、地图名）
    scenes/
      BootScene.js           # 启动：设缩放、进加载
      PreloadScene.js        # 资源加载页
      MainMenuScene.js       # 主菜单
      WorldScene.js          # 游戏主场景（走图）
      UIScene.js             # 常驻 HUD（并行场景）
      PauseScene.js          # 暂停/结算弹层
    entities/
      Player.js              # 玩家（8向帧动画预留）
      Npc.js                 # NPC 基类预留
      Enemy.js               # 妖兽预留
    systems/
      MapManager.js          # 可扩展大地图（5×5 块拼接）
      CombatSystem.js        # 战斗数值预留
      QuestSystem.js         # 任务预留
    ui/
      DialogueBox.js         # 对话预留
      HudView.js             # 血条/灵气条
    utils/
      helpers.js
  assets/
    images/characters/       # 8向待机/行走、立绘
    images/enemies/
    images/maps/             # 按地图名分子目录，如 qingyunshan/
    images/ui/
    audio/
    config/                  # JSON 配置表
  tools/                     # 批量命名等本地小工具说明
```

## 扩展约定（来自文档地图段）

- 单块贴图思路：5×5=25 张拼一大图；可往上下左右无限接新图  
- 新地图：丢素材 → 对 AI 说「根目录地图素材移到对应目录，命名青云山，可扩展」  
- 角色替换：白底立绘 → XMAI 按参考精灵换皮 → 重命名进 `assets/images/characters/`
